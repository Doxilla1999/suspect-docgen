# บันทึกประวัติการจับกุมลง Google Sheet

ระบบนี้ใช้ Google Apps Script เป็นตัวกลางฟรี ให้เว็บแอปส่งข้อมูล (ชื่อ-นามสกุล, เลขบัตรประชาชน, ตำบลที่จับ) ไปบันทึกลง Google Sheet ได้ โดยไม่ต้องมีเซิร์ฟเวอร์ของตัวเอง

## ขั้นตอนติดตั้ง (ทำครั้งเดียว)

1. ไปที่ [sheets.google.com](https://sheets.google.com) สร้างสเปรดชีตใหม่ ตั้งชื่อเช่น "บันทึกจับกุม สภ.นายายอาม"
2. เมนู **ส่วนขยาย (Extensions) → Apps Script**
3. ลบโค้ดเดิมในไฟล์ `Code.gs` ทิ้งทั้งหมด แล้วคัดลอกเนื้อหาจากไฟล์ `Code.gs` ในโฟลเดอร์นี้ไปวางแทน
4. แก้บรรทัด `const PIN = 'CHANGE_ME';` ให้เป็นรหัสผ่านที่ทีมจะใช้ร่วมกัน (เช่น `const PIN = 'nya2569';`) — ตั้งเป็นอะไรก็ได้ที่ทีมจำง่าย
5. กด **บันทึก** (ไอคอนแผ่นดิสก์ หรือ Ctrl+S)
6. กด **Deploy → New deployment**
7. ที่ "Select type" กดไอคอนเฟือง เลือก **Web app**
8. ตั้งค่า:
   - Execute as: **Me (บัญชีของคุณ)**
   - Who has access: **Anyone**
9. กด **Deploy** — ระบบจะขอ authorize สิทธิ์เข้าถึง Google Sheet ของคุณ กด "Authorize access" แล้วเลือกบัญชี Google ที่สร้างชีตไว้ ถ้ามีหน้าเตือน "Google hasn't verified this app" ให้กด **Advanced → Go to (ชื่อโปรเจกต์) (unsafe)** ได้เลย เพราะเป็นสคริปต์ของคุณเอง
10. หลัง Deploy เสร็จ จะได้ **Web app URL** หน้าตาประมาณ `https://script.google.com/macros/s/xxxxxxxxxxxx/exec` — **คัดลอก URL นี้ไว้**
11. เปิดไฟล์ `app_template.html` หา `const GAS_WEBAPP_URL = '';` แล้วใส่ URL ที่คัดลอกมาไว้ตรงกลาง `''`
12. รัน `python assemble.py` ใหม่เพื่อรวมเป็น `suspect-docgen.html`

## ทดสอบ

เปิด `suspect-docgen.html` กรอกชื่อ-นามสกุล-เลขบัตร-เลือกตำบล-ใส่รหัสผ่านทีม กด "บันทึกลง Google Sheet" แล้วเปิดสเปรดชีตดูว่ามีแถวใหม่เพิ่มมาไหม

## ข้อควรรู้เรื่องความปลอดภัย

- รหัสผ่าน (PIN) นี้เป็นแค่ตัวกันคนทั่วไปที่ไม่รู้รหัสไม่ให้บันทึกมั่ว **ไม่ใช่ระบบ login จริง** — ใครก็ตามที่เปิดดูโค้ดของเว็บแอป (กด view source) จะเห็น URL ของ Apps Script ได้ แต่จะบันทึกข้อมูลได้ก็ต่อเมื่อรู้ PIN ที่ถูกต้องเท่านั้น
- ถ้าอยากได้ระบบ login แยกรายบุคคลจริงๆ (รู้ว่าใครบันทึกอะไรเมื่อไหร่) ต้องใช้ Firebase Auth หรือระบบที่ใหญ่กว่านี้
- เลขบัตรประชาชนเป็นข้อมูลส่วนบุคคลอ่อนไหว ควรตั้งสิทธิ์การเข้าถึง Google Sheet เองให้จำกัดเฉพาะบัญชี Google ของทีม (Share เฉพาะคน) ไม่ควรตั้งเป็น "เปิดให้ทุกคนดูได้"
