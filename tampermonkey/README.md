# Auto-fill เว็บราชการด้วย Tampermonkey

แทนที่ bookmarklet เดิม (`dopa_bookmarklet/`) — ใช้ Tampermonkey แทน เพราะจัดการได้หลายเว็บในสคริปต์
เดียว (DOPA ตอนนี้ + รายงานอัยการ `ptd.ago.go.th` ในอนาคต) และฝังปุ่มลอยในหน้าเว็บให้เลย ไม่ต้องไปกด
bookmark แยก

**ไม่กดบันทึก/ส่งฟอร์มให้เองเด็ดขาด** — กรอกช่องให้เท่านั้น ต้องตรวจสอบและกดปุ่มบันทึกในเว็บราชการเอง
ทุกครั้ง

## วิธีติดตั้ง (ทำครั้งเดียว)

1. ติดตั้งส่วนขยาย **Tampermonkey** จาก Chrome Web Store: https://chromewebstore.google.com/detail/tampermonkey/dhdgffkkebhmkfjojejmpbldmpobfkfo
2. คลิกไอคอน Tampermonkey ที่มุมขวาบนของเบราว์เซอร์ → **Create a new script...**
3. ลบโค้ดตัวอย่างที่ขึ้นมาให้หมด แล้วคัดลอกเนื้อหาทั้งหมดจากไฟล์ `suspect-docgen-autofill.user.js`
   ในโฟลเดอร์นี้ไปวางแทน
4. กด **Ctrl+S** เพื่อบันทึกสคริปต์ (Tampermonkey จะเปิดใช้งานให้อัตโนมัติ)

## วิธีใช้งาน

1. เปิดเว็บแอป `suspect-docgen.html` กรอกข้อมูลคดีตามปกติ
2. กดปุ่ม **"คัดลอกข้อมูลสำหรับ DOPA"** ในแผง "รายงานผลการปฏิบัติ (LINE)"
3. ไปที่เว็บ `https://arrest.dopa.go.th/.../detainee/` (ล็อกอินไว้แล้ว) — จะเห็น**ปุ่มลอยสีทอง
   "📋 กรอกจาก suspect-docgen"** อยู่มุมล่างขวาของหน้าจอ
4. กดปุ่มนั้น ระบบจะกรอกช่องที่ทำได้ให้ พร้อมเด้งข้อความบอกว่าช่องไหนต้องเลือกเอง
5. **ตรวจสอบทุกช่องให้ถูกต้องก่อนกดปุ่ม "เพิ่มสถานที่" เอง**

## สถานะตอนนี้

- ✅ หน้า `detainee/` ("แจ้งการควบคุมตัว" — ขั้นตอนที่ 1): กรอกได้แล้ว
- ⏳ หน้า `update_place/` ("เพิ่มผู้ถูกควบคุมตัว" — ขั้นตอนที่ 2): ปุ่มขึ้นให้แล้วแต่ยังกรอกไม่ได้จริง
  (แจ้งเตือนไว้เฉยๆ) — รอตัวอย่างหน้าเว็บจริงเพื่อดูโครงสร้างฟอร์ม
- ⏳ รายงานอัยการ (`ptd.ago.go.th`): ยังไม่เริ่ม — จะเพิ่ม `@match` ของเว็บนี้เข้าไปในสคริปต์เดียวกันได้
  เมื่อได้ตัวอย่างหน้าเว็บมาดู

## ถ้าแก้สคริปต์ในโปรเจกต์แล้วอยากอัปเดตในเบราว์เซอร์

เปิด Tampermonkey Dashboard → คลิกสคริปต์นี้ → แก้/วางโค้ดใหม่ → Ctrl+S เหมือนเดิม
(ไม่มีขั้นตอนแปลง/encode เหมือน bookmarklet แล้ว แก้ไฟล์ตรงๆ ได้เลย)
