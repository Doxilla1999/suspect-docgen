# ระบบสร้างเอกสารผู้ต้องหา — สภ.นายายอาม

โปรเจกต์นี้สร้างเว็บแอปไฟล์เดียว (`suspect-docgen.html`) ที่ใช้กรอกข้อมูลผู้ต้องหาครั้งเดียว
แล้วดาวน์โหลดเอกสาร Word ที่เกี่ยวข้องได้ทันที (ปยส.115, ส่งตรวจปัสสาวะ, ใบปะหน้าส่งศาล,
บันทึกยินยอมตรวจโทรศัพท์ ม.80, ประวัติบุคคล 4 ด้าน + ภาพประกอบ)

## โครงสร้างไฟล์

```
generate_templates.py   สร้างไฟล์ .docx ต้นแบบทั้งหมด (ใช้ python-docx) -> เขียนลง build/
assemble.py              ฝังไฟล์ .docx (เป็น base64) เข้าไปใน app_template.html -> ได้ suspect-docgen.html
app_template.html        เว็บแอป (HTML/CSS/JS ล้วน ไม่มี build step อื่น) พร้อมช่อง __B64_..__ ให้ assemble.py แทนที่
garuda.png                ตราครุฑ ฝังในหัวกระดาษเอกสารราชการ
placeholders/            รูปตัวอย่าง 4 ด้าน (หน้าตรง/หลัง/ซ้าย/ขวา) ใช้เป็นค่าเริ่มต้นก่อนอัปโหลดรูปจริงในเว็บแอป
build/                   (สร้างอัตโนมัติ) ไฟล์ .docx ที่ generate_templates.py สร้างออกมา
```

## วิธีรัน

ต้องมี Python 3 และไลบรารีตาม `requirements.txt`:

```bash
pip install -r requirements.txt --break-system-packages   # หรือใช้ virtualenv ตามปกติ

python3 generate_templates.py   # สร้างไฟล์ .docx ทั้งหมดใน build/
python3 assemble.py             # รวมเป็น suspect-docgen.html ไฟล์เดียว
```

เปิด `suspect-docgen.html` ด้วยเบราว์เซอร์ได้เลย (ดับเบิลคลิก หรือ `open suspect-docgen.html`) —
ไม่ต้องมีเซิร์ฟเวอร์ ทำงานฝั่งไคลเอนต์ทั้งหมด ข้อมูลที่กรอก/บันทึกเคสจะเก็บอยู่ในเบราว์เซอร์ของผู้ใช้เอง
(ผ่าน `window.storage` ซึ่งเป็น API เฉพาะของ Claude.ai artifacts — ถ้าจะรันเป็นเว็บทั่วไปนอก Claude.ai
ต้องเปลี่ยนส่วนนี้เป็น localStorage หรือ backend อื่นแทน ดูหมายเหตุท้ายไฟล์นี้)

## แก้ไข/ปรับแต่งเอกสาร

- แก้เนื้อหา/ฟอร์แมตของแต่ละเอกสาร: แก้ที่ `generate_templates.py` (แต่ละเอกสารมีคอมเมนต์ `# ---------- N. ...`
  คั่นเป็นส่วนๆ) แล้วรัน `python3 generate_templates.py && python3 assemble.py` ใหม่
- แก้ฟอร์ม/ฟิลด์ในเว็บแอป หรือ logic การกรอกอัตโนมัติ: แก้ที่ `app_template.html` โดยตรง (ไม่ต้องรัน
  generate_templates.py ใหม่ถ้าไม่ได้แก้ตัวเอกสาร) แล้วรัน `python3 assemble.py` อย่างเดียวพอ
- ทุกเอกสารใช้ระบบ tag แบบ `{ชื่อฟิลด์}` ธรรมดา — `assemble.py`/เว็บแอปจะแทนที่ตอนกดสร้างเอกสาร
  (ดู `DOC_INFO` และ `buildTagMap()` ใน `app_template.html`) ถ้าเพิ่ม tag ใหม่ในเอกสาร ต้องไปเพิ่มการ
  แมปใน `buildTagMap()` ด้วยไม่งั้นจะโชว์ `{tag_name}` ค้างอยู่ในไฟล์ที่สร้างออกมา

## หมายเหตุสำคัญ

- เอกสาร "ปยส.115", "ส่งตรวจปัสสาวะ", "ใบปะหน้าส่งศาล", "บันทึกยินยอมตรวจโทรศัพท์ ม.80" ใช้ถ้อยคำจาก
  แบบฟอร์มต้นฉบับที่ทางสถานีอัปโหลดให้ Claude อ่านตอนพัฒนา — ไม่ได้แต่งขึ้นเอง
- "ประวัติบุคคล 4 ด้าน" จัดรูปแบบตามตัวอย่างจริงที่ทางสถานีส่งมาเทียบให้
- ทุกเอกสารเป็นเครื่องมือช่วยร่าง ไม่ใช่คำแนะนำทางกฎหมาย ควรตรวจทานก่อนใช้งานจริงทุกครั้ง
- `window.storage` (บันทึกเคส/ตั้งค่าหน่วยงาน) ใช้ได้เฉพาะตอนเปิดเป็น Claude.ai artifact เท่านั้น ถ้า
  เอา `suspect-docgen.html` ไปโฮสต์เป็นเว็บทั่วไป ฟีเจอร์บันทึก/โหลดเคสจะไม่ทำงานจนกว่าจะเขียนส่วนเก็บ
  ข้อมูลใหม่ (เช่น localStorage หรือฐานข้อมูลจริง) มาแทน — ส่วนสร้างเอกสาร Word (JSZip) ทำงานได้ปกติ
  ไม่ต้องพึ่ง window.storage
