# Auto-fill เว็บ DOPA (arrest.dopa.go.th) — ขั้นตอนที่ 1

เว็บแอป suspect-docgen กับเว็บ DOPA เป็นคนละโดเมนกัน สคริปต์จากเว็บเราสั่งงานเว็บ DOPA ตรงๆ ไม่ได้
(ข้อจำกัดความปลอดภัยของเบราว์เซอร์) วิธีที่ทำได้คือใช้ **Bookmarklet** — ปุ่ม bookmark พิเศษที่กด
ตอนอยู่บนหน้าเว็บ DOPA เอง (ที่ล็อกอินค้างไว้อยู่แล้ว) มันจะอ่านข้อมูลจาก clipboard (ที่เว็บแอปเรา
คัดลอกให้) มากรอกลงฟอร์มให้ — **ไม่กดบันทึก/ส่งให้เองเด็ดขาด** ต้องตรวจสอบและกดปุ่มในหน้าเว็บ DOPA เอง

## ⚠️ ตอนนี้ทำได้แค่ "ขั้นตอนที่ 1" เท่านั้น

เว็บ DOPA มี 2 หน้า:
1. **`arrest/app/detainee/`** — "แจ้งการควบคุมตัว" (สถานที่ + เจ้าหน้าที่ผู้แจ้ง) ← **bookmarklet นี้ทำหน้านี้**
2. **`arrest/app/update_place/`** — "เพิ่มผู้ถูกควบคุมตัว" (ชื่อ/เลขบัตร/ข้อหาของผู้ถูกจับจริงๆ) ← ยังทำไม่ได้
   เพราะยังไม่มีตัวอย่างหน้าเว็บนี้ให้ดู — ถ้าอยากให้ทำต่อ ช่วย Save Page As หน้านี้ (หลังกด
   "+ เพิ่มผู้ถูกควบคุมตัว" ให้เห็นช่องกรอกครบ) แล้วส่งมาเหมือนที่ส่งหน้าแรกมาให้

หน้าที่ 1 ที่ทำได้ตอนนี้จะกรอกให้อัตโนมัติ: ชื่อสถานที่, วันเวลาควบคุมตัว, จังหวัด/อำเภอ/ตำบล
(พยายามเลือกให้ — ถ้าหาชื่อในรายการไม่เจอจะเตือนให้เลือกเอง) — ส่วน "1.2 เจ้าหน้าที่ผู้รับผิดชอบ"
กับ "คำสั่งที่ให้มีการควบคุมตัว" ยังไม่กรอกให้ เพราะต้องตัดสินใจเองหน้างาน (เป็นคนเดียวกับข้อ 1.1
หรือไม่ / เหตุแห่งคำสั่งคืออะไร)

## วิธีติดตั้ง (ทำครั้งเดียว)

1. เปิดไฟล์ `bookmarklet_url.txt` ในโฟลเดอร์นี้ คัดลอกข้อความทั้งหมด (เริ่มด้วย `javascript:`)
2. ใน Chrome กด **Ctrl+Shift+O** เปิด Bookmark Manager
3. คลิกขวา → **Add new bookmark**
4. **Name**: ตั้งชื่ออะไรก็ได้ เช่น "กรอก DOPA อัตโนมัติ"
5. **URL**: วางข้อความที่คัดลอกมาจาก `bookmarklet_url.txt`
6. กด **Save**
7. (แนะนำ) ลากปุ่มนี้ไปไว้ที่แถบ Bookmarks bar (กด Ctrl+Shift+B เปิดแถบถ้ายังไม่เห็น) จะได้กดง่ายๆ

## วิธีใช้งาน

1. เปิดเว็บแอป `suspect-docgen.html` กรอกข้อมูลคดีตามปกติ
2. กดปุ่ม **"คัดลอกข้อมูลสำหรับ DOPA"** (อยู่ในแผงเดียวกับ "รายงานผลการปฏิบัติ")
3. ไปที่เว็บ `https://arrest.dopa.go.th/.../detainee/` (ล็อกอินไว้แล้ว)
4. กดปุ่ม bookmarklet ที่สร้างไว้
5. ระบบจะกรอกช่องที่ทำได้ให้ พร้อมเด้งข้อความบอกว่าช่องไหนต้องเลือกเอง
6. **ตรวจสอบทุกช่องให้ถูกต้องก่อนกดปุ่ม "เพิ่มสถานที่" เอง** — bookmarklet ไม่กดให้

## ถ้าแก้ข้อมูลในเว็บแอปแล้วอยากได้ bookmarklet ใหม่

ไฟล์ `bookmarklet_url.txt` สร้างจาก `fill_step1.js` — ถ้าแก้ `fill_step1.js` แล้ว ให้บอก Claude
ว่า "regenerate bookmarklet_url.txt" จะสร้างไฟล์ใหม่ให้ตรงกับโค้ดล่าสุด
